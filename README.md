# Airbnb Data Analysis Project

This project explores an Airbnb dataset using Python to uncover insights about pricing, room types, neighborhood distributions, and user engagement over time. The goal is to understand hosting trends and listing behaviors using data visualization and basic statistical analysis.

## 📦 Dataset
The dataset includes listings from various New York neighborhoods with features such as:
- Price
- Room type
- Host details
- Number of reviews
- Geographic location
- Availability

## 🧹 Data Cleaning
- Checked and handled missing values
- Removed duplicate entries
- Standardized and transformed key columns

## 📊 Analysis Questions Answered
1. **What is the distribution of listing prices?**
   - KDE and histogram plots show a wide variety of price ranges with no strong central tendency.
2. **How are different room types distributed?**
   - Visualized the frequency of room types across listings.
3. **What neighborhoods have the most listings?**
   - Identified top areas for Airbnb activity.
4. **Is there a link between price and room type?**
   - Found correlations between room type and pricing using box plots.
5. **How do review counts change over time?**
   - Tracked trends in customer reviews to understand platform usage patterns.

## 📈 Tools Used
- Python (Pandas, NumPy)
- Seaborn & Matplotlib for visualization
- Jupyter Notebook

## 📌 Conclusion
This project provided hands-on experience in EDA (Exploratory Data Analysis) and helped answer relevant business questions that can support Airbnb hosts and customers in decision-making.
